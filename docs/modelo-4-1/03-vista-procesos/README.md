# 03. Vista de procesos

Describe cómo se ejecuta el sistema durante una consulta y un pago, incluyendo
interacciones síncronas, tareas asíncronas y manejo de errores.

## Pendientes

- Documentar la secuencia de búsqueda, consulta, validación y pago.
- Identificar operaciones síncronas y notificaciones asíncronas.
- Definir qué sucede ante rechazo, timeout, duplicidad o reintento.
- Precisar las transiciones del pago: iniciado, validando, procesando,
  aprobado, rechazado, pendiente y cancelado.
