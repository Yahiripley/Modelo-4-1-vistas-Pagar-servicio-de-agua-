# 04. Vista de desarrollo

Organiza la solución desde la perspectiva del código: módulos, paquetes,
componentes, interfaces y dependencias entre ellos.

## Pendientes

- Definir la estructura de módulos de la aplicación.
- Ubicar controladores, modelos, vistas y servicios.
- Separar adaptadores de sistemas externos de la lógica del dominio.
- Definir componentes de prueba y dobles para integraciones.
- Documentar reglas de dependencia y nombres de paquetes.
